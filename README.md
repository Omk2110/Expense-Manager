# Expense Manager 💰

A beautifully designed, responsive Flutter application for tracking personal expenses. Built with Material 3, it offers a seamless experience across different screen sizes and supports both light and dark themes.

## ✨ Features

*   **Add & Manage Expenses:** Easily add new expenses with a title, amount (in ₹), date, and category.
*   **Categorization:** Organize your spending into different categories (e.g., Work, Leisure) to better understand your habits.
*   **Interactive Chart:** Visualize your expenses dynamically through an interactive chart that updates as you add or remove items.
*   **Responsive Design:** The UI automatically adapts to different screen sizes, providing an optimal layout whether you're using a mobile phone in portrait mode or a wider tablet screen in landscape.
*   **Light & Dark Mode Support:** Full support for system-wide light and dark themes, carefully styled with custom color schemes.
*   **Undo Deletion:** Accidentally deleted an expense? A snackbar allows you to quickly undo the action.
*   **Input Validation:** Ensures you provide valid amounts and complete information before saving an expense.

## 🛠️ Built With

*   **Flutter & Dart:** For cross-platform UI development.
*   **Material 3:** Modern design system for beautifully styled components.
*   **intl:** For formatting dates correctly.
*   **uuid:** For generating unique identifiers for each expense item.

## 🚀 Getting Started

Follow these steps to run the application on your local machine:

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/Omk2110/Expense-Manager.git
    ```
2.  **Navigate into the project directory:**
    ```bash
    cd Expense-Manager
    ```
3.  **Get Flutter packages:**
    ```bash
    flutter pub get
    ```
4.  **Run the app:**
    ```bash
    flutter run
    ```
